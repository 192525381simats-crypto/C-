Encryption Details

Algorithm: AES-256-GCM
Key derivation: PBKDF2 with SHA-256 and a random salt
Iterations: 310,000
Nonce: Fresh random 96-bit nonce for each vault save
Integrity: GCM authentication tag detects tampering.

The vault's complete account list is serialized as JSON and encrypted before being stored in browser local storage. The master password is never stored.

Encrypted File Handling

Export a backup containing only the encrypted vault data. Import a previously exported backup to replace the current vault.

Settings

Lock the vault when you finish. Keep your master password safe; it cannot be recovered if forgotten.

About

Project: Cyber Security Password Manager for Secure Password Storage

Purpose: Store account credentials in an encrypted vault and allow the owner to manage them after unlocking with a master password.

Academic prototype using browser Web Crypto API. For production use, additional security review and platform protections are required.
